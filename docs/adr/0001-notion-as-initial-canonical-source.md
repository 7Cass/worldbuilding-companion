# Notion as the Initial Canonical Source

The product starts as a Notion-first companion app: the user's worldbuilding canon lives in Notion, while the companion app keeps only derived state such as indexes, cache, relationships, analysis, and generated artifacts. This preserves the user's existing Notion workflow and avoids making the new app the system of record before it has earned that role, at the cost of designing around Notion's API and synchronization constraints.
